Data Breaches — Practical Lab

1. Lab Objective

To analyze data breaches and security incidents, identify exposed information and security weaknesses, and recommend appropriate prevention methods.

3. Incident Analysis

When investigating a security incident, identify the following:

- Affected Asset: The system, device, database, or network affected.
- Exposed Data: The information accessed, stolen, or disclosed.
- Attack Vector: The method used to gain unauthorized access.
- Security Weakness: The vulnerability, misconfiguration, or control failure that enabled the incident.
- Impact: The consequences for users or the organization.
- Prevention: The security controls that could reduce the likelihood or impact of a similar incident.

4. Lab Takeaways

- Identify what information or assets were exposed or compromised.
- Understand the difference between a vulnerability, an exploit, and an impact.
- Recognize common security weaknesses, including unpatched software, compromised credentials, and cloud misconfigurations.
- Recommend appropriate controls based on the underlying cause.
- Verify real-world incidents using reliable sources.
- Distinguish documented incidents from hypothetical course scenarios.

5. Key Security Principle

Identify → Investigate → Document → Prevent
