# Protecting Your Devices and Networks

## 1. Protecting Computing Devices

Before using a new device, apply essential security measures.

- **Firewall:** Filters network traffic and helps block unauthorized access.
- **Antivirus and Ani spyware:** Detect and help remove malware and spyware.
- **OS and Browser Updates:** Install security updates and patches to fix known vulnerabilities.
- **Password Protection:** Protect devices and accounts with strong, unique passwords.
- **Data Encryption:** Protects sensitive information from unauthorized access.
- **Software Sources:** Download applications only from trusted sources.

**Key Takeaway:** Keep devices updated, protected, and configured securely.

---

## 2. Firewall and Windows Security

A **firewall** monitors and filters incoming and outgoing network traffic according to security rules.

### Firewall Filtering
A firewall may filter traffic based on:
- IP addresses
- Network ports
- Applications and network protocols

### Windows Firewall Network Profiles

- **Private:** For trusted networks, such as a home network.
- **Public:** For untrusted networks, such as public Wi-Fi.
- **Domain:** For networks managed by an organization.

### Microsoft Defender Firewall

- Keep the firewall enabled.
- Allow applications through the firewall only when necessary.
- Advanced settings allow administrators to manage inbound and outbound rules.

**Key Takeaway:** A firewall reduces network security risks but does not replace other security measures.

## 3. IoT Security

**Internet of Things (IoT):** Physical devices connected to a network or the internet.

Examples include smart cameras, smart TVs, and connected home appliances.

### Security Risks
- Outdated firmware and software vulnerabilities.
- Weak or default passwords.
- Unnecessary internet or network exposure.
- A compromised IoT device may expose other devices on the local network.

### Protection
- Change default passwords.
- Update firmware regularly.
- Disable unnecessary services.
- Use a separate guest network or IoT network when supported.

### Shodan

Shodan is an internet-connected device search engine that helps identify publicly exposed devices and services.

Security researchers use it to study internet exposure and identify potential security risks.

**Key Takeaway:** Exposed devices are not necessarily vulnerable, but unnecessary exposure increases risk.

## 4. Home Wi-Fi Security

### SSID

**SSID (Service Set Identifier):** The name used to identify a Wi-Fi network.

Security practices:
- Change the default SSID if it reveals unnecessary information.
- Change default router credentials.
- Use strong, unique Wi-Fi passwords.
- Hiding the SSID alone does not provide adequate security.

### Wi-Fi Encryption

- **WPA3:** Prefer when supported by your devices.
- **WPA2-AES:** A suitable option for compatible older devices.
- **WEP:** Obsolete and insecure; avoid using it.

### KRACK

**KRACK (Key Reinstallation Attack):** A class of attacks exploiting weaknesses in the WPA2 protocol.

Protection:
- Keep routers and connected devices updated.
- Use secure Wi-Fi encryption.
- Prefer HTTPS for web browsing.

**Key Takeaway:** Use modern Wi-Fi security and install router firmware updates.

---

## 5. Public Wi-Fi Security

Public Wi-Fi may expose users to fake hotspots, traffic interception, and other network threats.

### Best Practices
- Avoid sensitive activities on untrusted networks when safer alternatives are available.
- Verify the network name with the legitimate provider.
- Use HTTPS websites.
- Use a trusted VPN when appropriate.
- Disable file and media sharing on public networks.
- Keep your operating system and applications updated.

### VPN

**Virtual Private Network (VPN):** Creates an encrypted connection between a device and a VPN server.

A VPN helps protect traffic between the device and VPN server, but it does not guarantee complete anonymity or protect against every threat.

### Bluetooth Security

Potential risks include unauthorized connections and attacks against vulnerable devices.

Protection:
- Turn Bluetooth off when it is not needed.
- Keep devices updated.
- Avoid accepting unexpected pairing requests.
- Use non-discoverable mode when appropriate.

**Key Takeaway:** Use wireless connections carefully, especially on public networks.
